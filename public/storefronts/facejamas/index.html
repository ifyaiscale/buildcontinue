BEFORE YOU MAKE IT

Personalization, privacy and checkout.

What kind of photo works best?

A clear, well-lit image with the face visible and enough resolution for clean personalization. JPEG, PNG and WebP files up to 10 MB are accepted.

Is my uploaded photo public?

No. The source file is stored in a private media bucket. The storefront cart carries an opaque personalization ID and proof, not the image itself or a public source URL.

Can I add a product before uploading?

No. A valid secure upload is required before a FaceJamas item can be added as a personalized cart line, which helps prevent incomplete fulfillment orders.

Can I use the same photo on more than one product?

Yes. After one secure upload, the current storefront can attach that personalization to multiple FaceJamas product formats in the same shopping session.

How is the final price confirmed?

The storefront shows the current synced product price, but Shopify remains authoritative. Limitless recalculates product availability, tax and the USD total before payment.

How much is shipping?

The current launch policy includes free standard shipping. Optional priority processing is shown separately at checkout when available.

Does the browser preview guarantee exact print placement?

No. The local preview confirms which source photo you selected. Exact manufactured placement depends on the production template used during fulfillment.
