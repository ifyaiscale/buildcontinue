# Project continuity

- Read `docs/HANDOFF.md` before starting or resuming work. Check live state rather than treating historical screenshots or setup notes as current evidence.
- For storefront-cart work, also read `docs/CART_STOREFRONT_HANDOFF.md`; it is the current browser-to-checkout contract and records the deliberate public-payment/personalization limitations.
- Update the handoff with each completed shipment: completed work, verified behavior, limitations/blockers, and the ordered next-step plan.
- Commit and push completed code, tests and documentation to the thread's authorized GitHub branch. Confirm publication before reporting it.
- Never commit runtime secrets, `.env.local`, databases, private attachments or unrelated workspace changes. Keep user guidance step by step and never request credential values in chat.
